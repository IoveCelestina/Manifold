当我写成这样时：
下面展示一些 `内联代码片`。

```python
import random
list = []
n = int(input())
def examination(n):
    j = 0
    o = 0
    for i in range(n):
        list.append(random.randint(0,1000))
        if list[i]%2 == 0:
            o+=1
        else:
            j+=1
    return o,j
print(examination(n))       
```
这样就不报错了 ，就引起了我的疑问，通过查资料问老师我解开了我的疑惑
![在这里插入图片描述](/csdn-assets/119762944/5218b82f171f262a.jpeg)
当我写了“j+=1”这句语句，我就是在为其绑定一个新值，但j,o是这个函数里的局部变量，我并未在这其中定义过它的值，所以报错
