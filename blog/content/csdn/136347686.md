## 01背包，但是bit
[题目链接](https://ac.nowcoder.com/acm/problem/267681)

**题目大意:**
n件物品每个物品有重量和价值,但所选物品的总重量并不是每件物品的重量和，而是所有所选物品的重量进行按位或运算的结果。

**输入:**
1.t
2.n，m表示n件物品，背包最大重量
3.每件物品的v,w

**分析:**
诈骗题。既然是或运算，把m看成二进制，考虑两种情况.
case 1:w[i]包含m的最高位1
case 2:w[i]不包含m的最高位1
如果w[i]的最高位位数比m的最高位位数高，或之后会比m大，不用考虑。

对于case 2,假设m=10110101,那么最大重量就是01111111,如果w[j] | 01111111=01111111，那么这个物品就可以选上(为什么不可以是w[j]<01111111呢?这个一会儿说)

对于case 1,也会分成两种情况
case 3:选次高位的1
case 4:不选次高位的1

对于case 4:最大重量是10011111,如果用小于判断的话，无法保证m的第二，第三位二进制数是0,所以需要那样判断

对于case 3，又可以进行分类,但注意的是只有m等于1是可以进行分类讨论

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64 = long long;
#define ios ios::sync_with_stdio(0);cin.tie(0);cout.tie(0);

int n,m;
void solve(){
    cin>>n>>m;
    vector<int> v(n),w(n);
    i64 ans=0;int pre=0;
    for(int i = 0;i<n;++i) cin>>v[i]>>w[i];
    for(int i = 31;i>=0;--i){
        int x = pre;
        if((m>>i)&1){//不选第一类
            x +=(1<<i)-1;
            pre +=(1<<i);
        }
        i64 sum=0;
        for(int j = 0;j<n;++j){
            if((x|w[j])==x)sum+=v[j];
        }
        ans = max(ans,sum);
    }
    i64 sum=0;//还要判断最大重量就是m的情况
    for(int i = 0;i<n;++i){
        if((m|w[i])==m) sum+=v[i];
    }
    ans = max(ans,sum);
    cout<<ans<<"\n";
}

int main(){
    ios;
    int t;
    cin>>t;
    while(t--){
        solve();
    }

    return 0;
}
```
**remark:**
位运算一定要加()不然容易寄
