[题目在这里](https://codeforces.com/contest/1981/problem/B)

**题目大意：** 每过一秒$a_i$或运算的范围往左和右扩展一个数,问经过$i$秒$a_i$是多少,刚开始$a_i=i$

**分析:** 题目理解清楚了，发现就是一个区间或起来的数值是多少，区间是$[max(0,i-j),i+j](j是经过几秒)$。区间或值怎么算，一个结论是l,r按二进制从高位往低位找，第一个l是0，r是1的位置，从它到后面都变成1

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64 = long long;
#define ios ios::sync_with_stdio(0);cin.tie(0);cout.tie(0);
//对于一个数max(0,i-j)-i+j 拓展范围
//反过来看i-j也会拓展到i，对答案可能产生贡献
//问题就转化成了区间或值

i64 n,m,l,r;
void solve(){
    cin>>n>>m;
    l = max(0LL,n-m);
    r = n+m;
    if(l==r){
        cout<<l<<"\n";
        return;
    }
    for(int i = 30;i>=0;--i){
        if((r>>i&1)&&!(l>>i&1)){
            cout<<(l|((1LL<<(i+1))-1LL))<<"\n";
            return;
        }
    }
}

int main(){
    ios;
    int t;
    cin>>t;
    while(t--){
        solve();
    }
    return 0;
}
```
