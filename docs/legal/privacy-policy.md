## 1. 我们收集的信息

### 1.1 您主动提供

| 类别 | 字段 | 用途 |
|---|---|---|
| 账号 | 邮箱 | 登录、找回密码、重要通知 |
| 计费 | 充值订单号、第三方支付返回的交易号 | 财务对账、争议处理 |
| 二次验证 | TOTP 密钥（加密存储） | 安全登录 |

### 1.2 服务自动生成

| 类别 | 字段 | 用途 |
|---|---|---|
| 请求元数据 | 时间戳、请求 HTTP 方法、路径、状态码、token 输入 / 输出计数 | 计费、配额、故障排查 |
| 网络环境 | IP 地址、User-Agent | 反滥用、安全审计、地域统计（IP 仅保留最近 90 天） |
| 行为审计 | 登录时间、API key 创建 / 撤销、充值扣费 | 安全审计与争议处理 |

### 1.3 我们**不收集**

- **不持久化**您请求体（prompt）或响应体的明文。仅在转发上游过程中临时存在内存中。
- 我们**不读取**、不分析、不二次出售您的请求内容。
- 我们**不在终端植入 Cookie 之外的跟踪器**（如指纹、像素）。

> ⚠ **但请注意**：当您的请求被转发至上游（Anthropic、OpenAI 等），上游服务可能会按其自身隐私政策记录请求内容。我们对此无法控制。详见第 4 节。

## 2. 信息的使用

我们仅出于以下目的使用上述信息：

1. **服务交付**：路由请求、计费、配额管控；
2. **安全保护**：反滥用、检测异常登录、抵御攻击；
3. **故障排查**：定位错误码飙升、上游异常；
4. **法律义务**：响应有管辖权的执法部门合法请求；
5. **服务改进**：聚合脱敏统计（例如总请求量、错误率分布），**不指向个人**。

我们**不会**：

- 将您的个人信息用于训练任何模型；
- 出售您的个人信息给第三方；
- 在未经您明示同意的前提下向您发送营销邮件。

---

## 3. 信息共享

我们仅在以下情况向第三方共享信息：

1. **上游 API 服务商**：您的请求体会被转发到对应原厂（Anthropic、OpenAI、Google 等）。这是技术上不可避免的；
2. **支付服务商**：充值时由支付网关处理金额与订单号，**我们不接触您的银行卡 / 支付宝 / 微信完整资料**；
3. **基础设施服务商**：服务器托管商、CDN、备份对象存储商可能在为我们提供基础设施的过程中接触加密数据；
4. **法律强制**：有管辖权的法院、监管机构或执法部门依法要求时。

**对上游记录的内容，Manifold 不承担责任**。如您处理敏感数据，请评估上游政策再决定是否使用本服务。

## 5. 数据存储与保留

| 类别 | 保留期 |
|---|---|
| 账号基本信息 | 账号存续期间 + 注销后 30 天 |
| 请求元数据（不含请求体） | 12 个月 |
| 充值 / 扣费流水 | 5 年（财税合规要求） |
| 审计日志（登录、key 操作、管理员操作） | 12 个月 |
| 备份 | 滚动 7 天每日 + 12 个月每月归档 |
| IP 地址 | 90 天后哈希化或匿名化 |

到期数据将被**安全销毁或不可逆匿名化**。

## 6. 数据安全

- 传输层：HTTPS（TLS 1.3 / HTTP/3 QUIC）
- 静态加密：数据库密码与 TOTP 密钥 AES-256 加密；备份用 GPG (RSA 4096) 加密
- 访问控制：管理员后台仅限白名单 IP + 2FA
- 第三方上游：我们对上游 API 使用 OAuth 安全令牌，凭证不明文存放

**但请注意**：互联网上不存在 100% 的安全。如发生数据泄露，我们将在 72 小时内向您与监管机构通报。

## 7. 您的权利

依据 GDPR / CCPA / 个人信息保护法（取决于您所在地）等法规，您有权：

- **查阅**：导出您账号下的全部个人信息（控制台 → 设置 → 数据导出）；
- **更正**：修改不准确的信息（控制台直接编辑或提交工单）；
- **删除**：申请彻底删除账号与全部关联数据；
- **限制处理**：在争议解决期间限制我们使用您的数据；
- **数据可携**：以机器可读格式获取您的数据；
- **撤回同意**：撤回您此前给予的同意（撤回不影响此前合法处理）；
- **投诉**：向您所在地的数据保护机构投诉。

行使权利请联系：`<待填：privacy@yesterhaze.codes>`，我们将在 30 天内响应。
