# Manifold 退款政策

**生效日期**：`<待填：上线日>`
**最近更新**：`<待填>`

本政策约束您从 Manifold 服务申请退款的全部情形。**充值时即视为您接受本政策当时生效的版本**。

---

## 1. 总体原则

1.1 Manifold 是**预付费消费式**服务：您先充值至账户余额，再按实际请求量扣费。

1.2 已实际消费的余额（即用于 API 调用并产生上游计费的部分）**不予退还**。

1.3 未消费余额按下列规则处理。

---

## 2. 可退情形

我们将受理以下情形的退款申请：

### 2.1 服务方原因导致的不可用

- 因我们的**主动错误**导致您无法使用充值的服务，且 72 小时内未能修复；
- 我们**单方面终止运营**（即关闭整个服务，非个别功能下线）。

**退款范围**：未消费余额 100%。

### 2.2 重大计费错误

- 因我们的代码缺陷或数据错误，错误扣除您的余额。

**退款范围**：错误扣除的全部金额，并出具错误说明。

### 2.3 充值后 48 小时内未消费

- 您完成充值且**全程零消费**，并在 48 小时内提交退款申请。

**退款范围**：充值金额扣除支付通道实际收取的手续费后退还（通常为 1-3%）。

**例外**：若您账号下任何 API key 在此期间产生过任何请求（无论是否成功），即视为已消费，不再适用 48 小时退款条款。

### 2.4 重大政策变更不接受

- 我们对本退款政策或服务条款的重大变更，您在变更生效前 14 天明示书面拒绝。

**退款范围**：未消费余额 100%。

---

## 3. 不退情形

以下情形**不予退款**，请您在充值前充分知悉：

### 3.1 上游原厂事件

- 上游 API（Anthropic、OpenAI、Google 等）单方面变更条款、定价、可用性；
- 上游主动封停我们的账号；
- 上游服务故障、限流、区域屏蔽；
- 上游对您的具体请求作出拒绝响应（429 / 403 / 内容违规拒绝）—— 我们已为这些请求向上游支付费用；
- 上游降低单次请求的输出质量。

> 即使上述事件让本服务部分功能不可用，**这些失败的根本原因不在我们这边**。我们已在《免责声明》第 2 节明示告知此类风险。

### 3.2 用户原因

- 您的 API key 泄露被他人盗用消费；
- 您的网络环境无法访问本服务；
- 您所在司法管辖区对相关服务的限制或禁令；
- 您的请求被本服务正常的速率限制 / 配额机制拦截；
- 您填错请求参数、用错 API key、错调用模型导致的请求失败。

### 3.3 违规情形

- 您违反《服务条款》第 5 条用户行为规范的，我们冻结账号后**有权扣留全部未消费余额**作为违约金 / 损失补偿；
- 您通过欺诈、洗钱、盗刷支付通道方式充值的，**我们保留向相关执法机构移交记录的权利，且不予退款**。

### 3.4 单纯反悔

- 单纯改变主意、找到更便宜的替代服务、个人原因不再使用 —— 不属于退款情形（参见 2.3 的 48 小时窗口例外）。

## 4. 退款流程

### 4.1 提交申请

通过 `<待填：support@yesterhaze.codes>` 提交退款申请邮件，包含：

- 注册邮箱；
- 充值订单号或交易号；
- 申请退款的具体情形（对照本政策第 2 节）；
- 您希望退款到的原支付渠道（必须与充值渠道一致）。

### 4.2 审核

- 普通情形：**5 个工作日内**作出审核结论；
- 复杂情形（涉及大额、跨境支付、争议）：**最长 30 个工作日**。

### 4.3 退款执行

审核通过后，款项原路返还至充值渠道：

- 支付宝 / 微信：通常 1-3 个工作日到账；
- 银行卡（Stripe 等）：通常 5-10 个工作日到账；
- 部分小型支付通道：以通道实际处理时长为准。

支付通道的到账时间**不受我们控制**。

### 4.4 退款金额

最终退款金额 = 退款基数 − 支付通道实际收取的手续费 − 已发生的上游成本（如适用）。

我们不向您额外收取**退款手续费**。

---

## 5. 余额提现禁止

5.1 账号余额仅可用于本服务消费，**不可提现**至任何第三方账户。

5.2 任何要求将余额折现、转账、置换为礼品卡 / 加密货币 / 其他财产的请求**一律不予办理**。

5.3 本规则旨在符合中国及多数司法管辖区对预付费工具的反洗钱要求。

---

## 6. 服务终止时的余额处理

6.1 我们公告终止本服务后：

- **公告生效前**：您仍可正常消费余额；
- **公告生效后 60 天内**：您可申请未消费余额全额退款（按 4.1 流程）；
- **超过 60 天**：未申请退款的余额视为**自动放弃**，所得收入用于本服务的最终清算与未结清债务。

6.2 因不可抗力（含主体破产、清算、被执法部门冻结）导致的终止，余额返还按破产法定程序处理，**不保证可获全额**。

---

## 7. 优惠 / 赠送余额

7.1 通过活动、邀请奖励、补偿等方式获得的**非充值**余额：

- 不予退款；
- 不可提现；
- 仅在使用期内消费有效。

7.2 退款时优先扣减优惠余额，原充值部分按本政策处理。

## 8. 争议与升级

8.1 对退款决定有异议的，请通过 `<待填：dispute@yesterhaze.codes>` 升级。

8.2 升级仍未达成一致的，按《服务条款》第 13 条争议解决路径处理。

8.3 您在升级期间应**继续遵守本服务的全部规则**，不得通过支付通道恶意 chargeback / 强制退款。**违者**：我们将立即冻结账号、扣留全部余额、并保留向支付通道与执法部门移交证据的权利。

历史版本可向 `<待填：support@yesterhaze.codes>` 申请获取。
